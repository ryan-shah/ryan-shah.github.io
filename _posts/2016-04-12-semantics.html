This project was developed with a friend for the Cathacks 2 competition.

We created a program that analyzed a given text input, whether a book or a poem or song, and analyzed the emotial context of each line

This result was then used to pick a light and sound on a scale relative to how happy or sad the line was. These were then stringed together to create a unique audio/visual identifier for the piece, the visual portion displayed on a LED cube we had constructed.

The project was created using Python for the analysis and sound creation, and C for the arduino controlling the lights.

We won second place in the competition for our work, and later presented at the Kentucky Academy of Science's 2016 Annual Meeting, the program for which can be found here.
