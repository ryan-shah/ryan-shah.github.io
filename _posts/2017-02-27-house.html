This project was done as part of the DerbyHacks 2 competition.

During the course of this hackathon, I worked with a friend to implement common smart devices using a Raspberry Pi and arduino controller in a model dollhouse. Unfortunately, we were unable to secure a real home for the project.

We were able to use these two devices to host a website that allowed the control of a myriad of devices in the home that included:

  • Door Locks
  • Lights
  • A webcam
  • An elevator

We were even able to put a heat sensor in the "kitchen" to display alerts to the web-app.

Our project was built with varying technologies, using PHP for the website and C++/Python to control the sensors and lights.

We were awarded prizes for The Most Potential Value for the World/Biggest Market and by Firstbuild, the sponsor of the competition
