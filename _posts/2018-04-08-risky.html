I did this project with some of my friends as part of Cathacks 2018.

We created a tool called Risky Click, which connected to a user's Facebook and Twitter and scanned through the available images and texts posts for "questionable" content.

We created a python web-app that implemented Google Cloud's image processing api, as well as using Twitter and Facebook api's and developer tools to accomplish this.

For a more detailed examination of the project, please view the source code.
